Healthcare event reactions

How US healthcare stocks move around FDA decisions, clinical-trial readouts and CMS announcements — a descriptive event study.

Research snapshot · not investment advice · 2026-10-05
Verdict: no tradable edge. Across 197 usable events in 26 of 44 companies, average abnormal returns around these events are statistically indistinguishable from zero. Every realistic control — publication timing, trading costs, and multiple-testing correction — removes any apparent signal.

How it is built

  • Returns are market-model abnormal returns: each stock's return minus its benchmark-predicted return, estimated on a clean window before the event.
  • Timing is enforced — entry is only ever on or after the moment the news was public, so no look-ahead. (Relaxing this inflates returns several-fold; that lift is not real.)
  • Costs are stress-tested; the break-even one-way cost is below realistic spread-plus-impact for the small/mid-cap names where any signal concentrates.
  • Every event traces to a source — openFDA, SEC EDGAR, ClinicalTrials.gov, data.cms.gov — and a company is only ever attached through a verified name→ticker map.

Honest limits

  • Snapshot of a survivor universe; delisted companies are not included.
  • Events are sparse and cluster in a few large names, so power is low.
  • This page is a static read-only snapshot; the interactive tool and the look-up-any-company feature run on a live backend.
